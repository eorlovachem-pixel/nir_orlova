# SwarmChem — существующий код, математическое обоснование и дополнения

## 1. Краткое резюме (abstract)

В этот пакет включён **исходный код без переписывания**: E01, E02, их реальные тесты и два более ранних прототипа роевой динамики. Отдельно добавлен **новый проверочный модуль** `e02_harmonic_reference.py`: независимые матрицы $A$ и $B$, гармонический потенциал, аналитическое решение `scipy.linalg.expm`, энергетический баланс, спектральная оценка радиуса. Дополнение **не модифицирует** старый E02 и **не реализует** E03. Ниже приведено соответствие программных функций математическим определениям и указаны ограничения реального кода (М3–М4; [5, PDF с. 4–7; 6, печ. с. 46–47]).

## 3. E01: математический смысл функций

| Функция | Вход → выход | Смысл |
|---|---|---|
| `adjacency(n, kind)` | $N$, топология → $A\in\mathbb R^{N\times N}$ | Статический симметричный граф: `ring`, `complete`, `none`, `disconnected` |
| `effective_laplacian(a)` | $A$ → $L_A=(D_A-A)/N$ | Нормировка оператора согласования |
| `initial_velocities(n,dimension,seed)` | Размер и seed → $V_0\in\mathbb R^{N\times2}$ | Одинаковая инициализация во всех сравниваемых графах |
| `reference_solution(l,v0,times)` | $L_A,V_0,t$ → $V(t)$ | Эталон по спектральному разложению |
| `numerical_solution(l,v0,times)` | То же → численный $V(t)$ | SciPy `solve_ivp` с DOP853 |
| `disagreement(trajectory)` | $V(t)$ → $\|Q_NV(t)\|_F$ | Норма отклонений от среднего |
| `run_case(...)` | Сценарий → метрики | Сравнение ошибки, спектральной оценки, сохранения среднего |

Формула:

$$
\dot V=-L_AV,\qquad
L_A=\frac{D_A-A}{N},\qquad
V(t)=e^{-L_At}V_0.
$$

Это постановка линейного согласования [6, печ. с. 46–47 / PDF с. 67–68]. В коде $\lambda_2$ берётся от **уже нормированного** $L_A$; делить на $N$ ещё раз нельзя.

**Фактически перепроверено:** `12 passed`; `PASS: 36 runs`. Сценарии $N=4,8,16$, 3 seeds, 4 графа. E01 не использует химические конформеры.

## 4. E02: математический смысл функций

### Основное состояние

Исходный `e02_dynamics.py` интегрирует:

$$
y=\bigl(\operatorname{vec}(X),\operatorname{vec}(V),W\bigr),
\qquad |y|=2Nd+1.
$$

В исходном эксперименте $d=2$. Здесь $W$ — один скаляр накопленной диссипации, **не внутренняя координата частицы**.

| Функция | Смысл / формула | Проверка |
|---|---|---|
| `Parameters` | $k$, `preferred_distance`, $\varepsilon$, $\sigma$, $\kappa$ | Явные параметры учебного потенциала |
| `adjacency()` | Матрица $A$ для alignment | Симметрия, нулевая диагональ |
| `potential_and_force(q,kind,p)` | $P(X)$ и **согласованный** $F=-\nabla P$ | Конечные разности, сумма сил |
| `make_rhs()` | $\dot X=V$, $\dot V=F-\kappa L_AV$, $\dot W=\kappa V^\top L_AV$ | Баланс энергии |
| `total_energy()` | $H=\tfrac12\sum\|v_i\|^2+P(X)$ | Сохранение/диссипация |
| `disagreement()` | $\|V-\mathbf1\bar v^\top\|_F$ | Проверка скорости согласования |
| `relative_radius()` | **RMS**-радиус, не $R_{\max}$ | Расстояния относительно центра |
| `simulate()` | DOP853, временные ряды, метрики | Энергия, центр масс, NaN/Inf |
| `e02_run.py` | Сценарии и сохранение артефактов | CSV, PNG, config, environment |

Закон энергии для симметричного $A$:

$$
\dot H=-\kappa\operatorname{tr}(V^\top L_AV)\le0,\qquad
\dot W=\kappa\operatorname{tr}(V^\top L_AV),\quad
H(t)+W(t)-H(0)=0.
$$

Эта формула следует из **конкретного** градиентного потенциального поля и симметричного лапласиана; это не свойство всех возможных нейросетевых полей [5, PDF с. 4–7; 8, PDF с. 3–5].

### Реальные режимы E02

| `mode` | Силы | Alignment |
|---|---|---|
| `free` | Нет | Нет |
| `alignment` | Нет | Да |
| `potential` | `preferred` | Нет |
| `combined` | `preferred` | Да |
| `repulsion_alignment` | `repulsive` | Да |

**Фактически перепроверено:** `27 passed`; `PASS: 45 cases`. При исходном E02 потенциальные взаимодействия реализованы по **полному** графу; параметра независимого произвольного $B$ в его API нет.

### Риски, которые важно понимать начинающему исследователю

- Не путать `Parameters.epsilon` (сглаживание расстояния в `preferred`) с амплитудой гауссова отталкивания. В исходном `repulsive` амплитудой служит `Parameters.k`.
- Не путать численную невязку энергобаланса с доказательством глобальной ограниченности [7, PDF с. 3–5].
- Абсолютная энергия разных режимов включает разные потенциалы; сравнивать её значения **между режимами** как физическую энергию некорректно.
- `relative_radius()` — $R_{\mathrm{RMS}}$, а не $\max_i\|q_i-\bar q\|$.
- `adjacency()` исходного E02 ограничена **чётным** $N\ge4$; она ещё не приспособлена к произвольному числу наблюдаемых конформеров в E03.

## 5. Что добавлено в этом пакете: E02+ (отдельный модуль)

### Разделение двух графов

$$
L_A=\frac{D_A-A}{N}\quad\text{(alignment)},
\qquad
L_B=\frac{D_B-B}{N}\quad\text{(potential)}.
$$

- Граф $A$ может быть `ring` или `complete`.
- Граф $B$ может быть `complete`, `disconnected` или специально сгенерированным симметричным взвешенным графом `weighted`.
- Взвешенный граф специально используется для проверки случая $L_AL_B\ne L_BL_A$.

### Гармонический потенциал (новый эталон)

$$
P(X)=\frac k2\operatorname{tr}(X^\top L_BX),
\qquad F=-kL_BX.
$$

$$
\begin{bmatrix}\dot X\\\dot V\end{bmatrix}
=\begin{bmatrix}0&I\\-kL_B&-\kappa L_A\end{bmatrix}
\begin{bmatrix}X\\V\end{bmatrix}.
$$

`harmonic_matrix()` строит матрицу $M$, `integrated_case()` решает ODE через DOP853 и независимо вычисляет $e^{Mt}$. Для этого **не требуется** коммутативность лапласианов.

### Ограниченность относительного радиуса

При связном $B$ и $k>0$:

$$
R_{\mathrm{RMS}}^2(t)\le
\frac{2H_{\mathrm{rel}}(0)}{Nk\lambda_2(L_B)}.
$$

Если $\lambda_2(L_B)=0$, код возвращает `bound_applicable=False` и `bound_sq=None`, **не подставляет 0**. Это **аналитическая оценка** из спектральной теории и энергетического тождества [6, печ. с. 46–47; 8, PDF с. 3–5].

### Фактически измеренный результат

| Показатель | Результат 18 запусков |
|---|---:|
| Сценарии | **18/18** |
| Автотесты дополнения | **8/8** |
| Максимальная ошибка DOP853 против `expm` | $6.60\cdot10^{-11}$ |
| Максимальная абсолютная невязка энергии | $8.67\cdot10^{-11}$ |
| Максимальный дрейф средней скорости | $1.74\cdot10^{-15}$ |
| Максимальная ошибка движения центра | $3.79\cdot10^{-15}$ |
| Сценарии со связным $B$, где оценка применима | **12/18** |
| Пример ненулевого коммутатора $[L_A,L_B]$ | $\|[L_A,L_B]\|$ достигает $0.087$ |

Результаты сохранены в `code_extensions/results/metrics.csv`, `config.json` и `harmonic_reference_and_bound.png`. Проверен **отдельный модуль**; прежний E02 от его появления не изменился.

## 6. Что ещё НЕ внесено в старую реализацию

| Изменение | Почему полезно | Статус |
|---|---|---|
| Встроить независимый $B$ в `potential_and_force()` и `make_rhs()` | Единый интерфейс всех режимов | **План**, сейчас реализовано отдельно лишь для гармонического случая |
| Добавить `harmonic` к видам потенциала E02 | Тест точного линейного поля | **План**, эталон есть в add-on |
| Добавить $R_{\max}$ и $F_{\mathrm{RMS}}$ в старые CSV | Диагностика разлёта | **План** |
| Несколько длинных горизонтов $T$ для отталкивания | Проверка, не выдавая конечновременное наблюдение за теорему | **План E02.3** |
| Реализовать `torchdiffeq` и обучаемый кодировщик | Подготовить настоящую непрерывную ML-модель | **План E03** |
| Тест $N_{\mathrm{latent}}=N_{\mathrm{conformers}}$ | Строгое соответствие 1:1 | **Обязателен для E03**, не относится к E01–E02 |

## 7. Честный аудит раннего обучаемого прототипа

Файл `code_existing/ML_prototype/trainable_conformer_swarm.py` **не нужно выдавать за окончательную E03-модель**.

### Что реально есть

- `generate_rdkit_molecules()`: RDKit ETKDG-конформеры, MMFF-оценки энергии и 5 геометрических дескрипторов.
- `pair_descriptors()`: симметричные парные признаки.
- `TrainableSwarm`: одна `pair_net` для всех пар, параметры жёсткости/предпочтительной дистанции/alignment.
- Количество вычислительных частиц **совпадает с числом входных строк-конформеров**: $N=x.shape[0]$.
- `DeepSetsBaseline`: отдельный обучаемый агрегатор.
- `target` **создаётся кодом синтетически** из тех же геометрических и энергетических дескрипторов; экспериментальные значения свойств не используются.

### Чего пока нет и какие последствия

1. Используется **дискретный симплектический Эйлер** с фиксированными `steps` и `dt`, а не полноценный `torchdiffeq.odeint` [4, PDF с. 1–2].
2. Начальные $q_i(0)$ берутся из первых двух нормированных дескрипторов; отдельный обучаемый химический encoder пока не реализован.
3. В `forward()` итоговый readout получает `normal=x.mean(...)` и `base=Σ Boltzmann·x`. Поэтому предсказатель может научиться **обходить роевую динамику**, не полагаясь на её выход. Нужна абляция «только конечные состояния».
4. Для класса `TrainableSwarm` имеется `pair_net`, но никаких гарантий свойств будущего Neural ODE только из этого не следует.
5. Эксперимент с синтетической целью **не подтверждает** точности на реальном Sterimol или другой химической метке [2, с. 1–4; М1, PDF с. 5].

### Контрольные проверки для будущего E03

```python
# Псевдоконтракт для будущего обучаемого encoder, НЕ изменение E02.
assert latent_states.shape[0] == conformer_features.shape[0] # строго 1:1: N наблюдаемых конформеров -> N латентных частиц
# Переставить входные конформеры, проверить ту же перестановку состояний.
# Затем проверить неизменность предсказанного молекулярного свойства.
```

Сравнить полную модель, отключённую динамику, фиксированный оператор, Deep Sets при **одинаковых** данных, seeds и разбиениях по молекулам [3, PDF с. 2–3; М1, PDF с. 5].

## 9. Советы для следующего рабочего шага

1. **Не начинай с больших библиотек.** Разберись, почему у E01 и E02 разные состояния: $V$ против $(X,V,W)$.
2. **Повтори две формулы вручную:** $L_A=(D_A-A)/N$ и $F=-\nabla P$.
3. **Попробуй тест с `kappa=0`:** энергия должна сохраняться в пределах численной погрешности.
4. **Измени один граф $B$ на несвязный:** строгая глобальная оценка радиуса перестаёт применяться, хотя решатель продолжает работать.
5. **Переходи к E03 только после выбора target $y$.** Само наличие RDKit-конформеров ещё не делает данные подходящими для регрессии реального свойства.
